Methodology

How NeuroScan AI Works

A specialized convolutional neural pipeline built to ingest axial brain MRI scans, extract spatial features, and classify tumor manifestations.

01

Upload MRI

Upload a standard brain MRI image in JPG or PNG format via drag-and-drop or file selector.

02

Image Processing

The image is resized to 224×224 pixels and rescaled (1/255) to conform to the model's tensor input requirements.

03

Deep Learning

Sequential CNN extracts multi-scale edge, texture, and structural contours across multiple convolutional layers.

04

Prediction Result

Dense softmax activation returns the predicted class label along with individual class confidence probabilities.

Categories

Brain MRI Classification

The neural network was trained on 4 distinct radiological categories from MRI imaging datasets.

Class 0

Glioma

Originates in glial cells supporting neurons in the brain. Often infiltrative with variable grades, visible as irregular hypo/hyper-intense regions on T1/T2 MRI scans.

Read details
Class 1

Meningioma

Arises from the meningeal membranes enveloping the brain and spinal cord. Typically extra-axial and well-circumscribed, showing distinct contrast enhancement.

Read details
Class 2

Pituitary

Develops in the pituitary gland situated at the skull base (sella turcica). Radiologically identified through expansion of the sellar region.

Read details
Class 3

No Tumor

Represents control baseline MRI images without radiological signs of intracranial lesions, demonstrating symmetrical cerebral anatomy.
